# Energy Attribution

A Home Assistant custom integration for attributing whole-home power consumption to selected Home Assistant entities.

## Installation

This repository is intended to be installed through HACS as a custom repository of type **Integration**.

After installation, restart Home Assistant and add **Energy Attribution** from **Settings → Devices & services → Add Integration**.

## Current status

This first packaged release provides the configuration-flow foundation and entity discovery needed for the commissioning workflow. The attribution/training engine will be developed on top of this stable installation base.
