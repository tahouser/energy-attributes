# EnergyIQ Artwork

Canonical EnergyIQ icon artwork for Home Assistant.

## Master
- `icon-master.svg` — canonical vector artwork.
- `icon-512.png` — 512×512 full-color raster master.

## Home Assistant brand assets
- `custom_components/energyiq/brand/icon.png` — EnergyIQ icon.
- `custom_components/energyiq/brand/icon@2x.png` — EnergyIQ high-resolution icon.
- `custom_components/energyiq/brand/logo.png` — same canonical icon asset until a separate wordmark asset is approved.

## Usage rule
All EnergyIQ user-facing icon surfaces use the same full-color artwork. The Home Assistant sidebar remains monochrome because that surface is registered through Home Assistant's icon mechanism rather than the brand image asset.

Do not redraw or substitute an MDI icon for the EnergyIQ brand artwork.
